# Retail Sales Analytics

## Project Overview

This project analyzes real-world retail transaction data using Python and pandas.

The dataset is the UCI Online Retail dataset, containing transactions from a UK-based online retailer between December 2010 and December 2011.

## Dataset

Source: UCI Machine Learning Repository

Dataset: Online Retail

https://archive.ics.uci.edu/dataset/352/online-retail

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- Jupyter Notebook

## Analysis Performed

- Data loading and cleaning
- Missing-value analysis
- Duplicate removal
- Transaction filtering
- Revenue calculation
- Product analysis
- Customer analysis
- Daily and monthly sales trends
- Country-level revenue analysis
- Customer segmentation
- High-value customer analysis
- Sales visualization

## Key Results

- Total Revenue: £8,887,208.89
- Unique Customers: 4,338
- Unique Products: 3,665
- Unique Transactions: 18,532
- Best Sales Month: November 2011
- Best Month Revenue: £1,156,205.61
- High-Value Customers: 1,085
- Top 10 Products Revenue Share: 9.96%

## Conclusion

The project demonstrates how real-world retail transaction data can be cleaned, analyzed, and visualized to identify sales trends, customer segments, and product performance.

These insights can support data-driven retail decisions such as customer retention, product promotion, inventory planning, and targeted marketing.
